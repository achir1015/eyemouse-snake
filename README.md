# 眼動鼠貪吃蛇

教・學・養・心安：像蟻人一樣縮小，在立體的 3D 空間裡用眼睛控制蛇，邊玩邊學。為漸凍人與行動不便的朋友設計。

- 下載與介紹：https://achir1015.github.io/eyemouse-snake/
- Windows 安裝程式：[EyeMouseSnake-Setup.exe](https://github.com/achir1015/eyemouse-snake/releases/latest/download/EyeMouseSnake-Setup.exe)

## 特色

- **用眼睛玩**：眼動鼠（Tobii）、網路攝影機眼控（MediaPipe，本機處理不上傳）、滑鼠、鍵盤；看著哪裡蛇就往哪裡游。
- **九個 3D 世界**：量子領域、太陽系、黑洞、微觀花園、恐龍時代、海底、荷花池、水溝、細菌世界。
- **教**：小柯機器人台灣華語語音動態教學。
- **學**：46 張科普知識卡（宇宙、黑洞、病菌由來與預防、害蟲定義與防範、恐龍）。
- **養**：護眼休息提醒、會長大的「我的小蛇」。
- **心安**：放鬆模式不會失敗；看不到眼睛自動暫停。
- 五種鏡頭視角、程式內更新。

## 開發

Godot 4.7.2（Forward+）。`tools/build_win.sh` 建置 Windows 安裝程式（Inno Setup 6）。

玩法概念參考 [NeuroSnake](https://github.com/matenestor/neurosnake)，程式全部重新實作。
